# 🎨 Interactive Color Picker

A simple and beautiful mini-project that changes the background color of the page to a random RGB shade every time you click the button.

## 🚀 Features
* Clean and minimalist design.
* Smooth layout centering using CSS Grid.
* Random RGB color generation using JavaScript.

## 🛠 Technologies Used
* **HTML5**[cite: 1]
* **CSS3** (Flexbox/Grid, custom button styling)[cite: 3]
* **JavaScript (ES6+)** (DOM manipulation, Math functions)[cite: 2]

## 💻 How to Run
1. Clone or download this repository.
2. Open `index.html` in any web browser[cite: 1].
